# 航班预订

这是一个处理机票查询与预订的流程技能。核心目标是在用户表达出行意图后，快速完成航班搜索、选择与预订，并给出明确的预订结果。

## 执行流程

### 步骤 1：识别出行意图与关键信息

从用户输入中提取以下信息：

| 信息项 | 必填 | 说明 |
|--------|------|------|
| 目的地 | ✅ | 如：北京、上海、广州、深圳 |
| 出发地 | ❌ | 默认由上下文或用户配置决定；未知时询问 |
| 日期 | ❌ | 未提供时询问用户，或使用最近的可用日期 |
| 人数/舱位 | ❌ | 默认 1 人经济舱 |

**示例用户输入与提取结果：**

| 用户输入 | 目的地 | 出发地 | 日期 |
|---------|--------|--------|------|
| "我想飞北京，帮我订票" | 北京 | 待定 | 待定 |
| "订一张去北京的机票" | 北京 | 待定 | 待定 |
| "帮我订一张去北京的机票" | 北京 | 待定 | 待定 |

### 步骤 2：搜索航班

调用航班搜索工具，优先使用 `flight_search`，不可用时使用 `web_search` 替代。

**查询输入格式**：以"目的地 + 航班/机票"为佳，保持简洁。

**示例查询：**
- `北京航班`
- `去北京机票`
- `去北京的航班`

搜索结果会返回航班列表，例如：
```
找到 5 个航班：CA1234、MU5678、CZ9012、HU3456、MF7890
```

### 步骤 3：确认或选择航班

- 如果搜索结果包含多个航班，向用户列出供选择；用户未指定时默认选择列表中的第一个航班。
- 如果必要信息（日期、乘客姓名等）缺失，主动询问用户，不要擅自猜测。
- 确认航班号后进入预订环节。

### 步骤 4：调用预订服务

调用预订技能（`flight_booking` 或 `booking_service`），设置触发描述为"用户要求订机票"或"订票请求"。

预订服务返回结果，例如：
```
预订成功，订单号 BK-REAL-001，航班 CA1234
```

### 步骤 5：向用户反馈结果

将预订结果完整告知用户，包括：预订状态、订单号、航班号、目的地。

## 输出格式

预订成功后，使用以下模板回复用户：

```
预订成功！
- 订单号：{订单号}
- 航班：{航班号}
- 目的地：{目的地}
```

**示例：**
```
预订成功！
- 订单号：BK-REAL-001
- 航班：CA1234
- 目的地：北京
```
